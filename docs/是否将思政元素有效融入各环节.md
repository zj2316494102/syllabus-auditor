# 维度：是否将思政元素有效融入各环节

## 基本信息

- 维度编码：`szysfyxrghj`
- 维度名称：是否将思政元素有效融入各环节
- 审核方式：LLM 审核
- LLM 调用次数：1 次
- 字段级编码：`szyr`
- 结果来源表：`audit_findings`
- 字段明细表：`audit_field_findings`
- LLM 调用记录：`llm_trace.calls[]`

## 判断目标

该维度只判断“思政元素融入”，不审核预期教学成效。

LLM 综合判断两类证据：

- 课程目标中的思政目标。
- 教学安排中的思政元素融入。

只有两类证据都存在，且能够形成关联，总维度才为“是”。任一部分缺失、空泛或无法与教学环节关联，总维度为“否”。

## Meta 兜底策略

payload 是主体证据。meta 只在结构化字段为空、缺失、明显不完整或存在相关抽取 warning 时作为辅助证据。

### 兜底触发

- `payload.kcmb.szmb` 为空、明显过短、只有模板化空话，或 `meta.extraction_warnings` 指向 `kcmb`。
- `payload.jxap.tm` 为空，或 `tm[].szyqjxx` 大量为空，或 `meta.extraction_warnings` 指向 `jxap`。

### 思政目标兜底区域

- `课程目标`
- `教学目标`
- `思政目标`
- `课程思政目标`
- `价值目标`
- `育人目标`

### 教学安排融入兜底区域

- `教学安排`
- `课程安排`
- `授课安排`
- `教学进度`
- `课程思政`

- `思政元素融入`

### 关键词辅助截取

- `思政`
- `立德树人`

- `价值观`

### 兜底限制

- meta 只进入 LLM 输入和 evidence，不回写 payload。
- 不能只因为 meta 中出现“课程思政”“思政元素”等关键词就判通过。
- 如果 payload 为空但 meta 有相关原文，原因或 evidence 中必须说明“结构化字段为空但原文疑似存在相关内容，需复核抽取”。
- 如果 payload 和 meta 都没有可判断内容，判“否”，原因写“未提供可判断的思政目标或教学安排融入信息”。

## 异常与兜底

- 未配置 LLM：维度判“否”，原因写“未配置 LLM，无法审核是否将思政元素有效融入各环节，需人工复核”。
- 返回非 JSON：维度判“否”，保存原始回答和解析异常。
- 返回“否”但 `reasons=[]`：自动补“模型未给出不通过原因，需人工复核”。
- 完整 prompt、原始回答、解析结果、解析异常都保存到 `llm_trace.calls[]`。
