# 维度：信息要素完整、符合模板、是否有中英文简介

## 基本信息

- 维度编码：`xxyzwzfhmb`
- 维度名称：信息要素完整、符合模板、是否有中英文简介
- 审核方式：规则审核
- 是否调用 LLM：否
- 结果来源表：`audit_findings`
- 字段明细表：`audit_field_findings`

## 判断目标

判断课程方案是否满足模板字段、章节、表格列要求。

“信息要素完整”和“符合模板”合并为内部判断 `mbxxyzwz`；“是否有中英文简介”单独形成内部判断 `zywjj`。

该维度不判断内容质量，只判断字段是否存在、是否非空、表格是否有必要列和有效行。

## 输入

读取 `payload`：

- `payload.jcxx`
- `payload.kczwjj`
- `payload.kcywjj`
- `payload.ybzsyq`
- `payload.jcjydcl`
- `payload.kcmb`
- `payload.jxnr`
- `payload.jxap`
- `payload.kcyq`
- `payload.kcyqb`

读取 `meta` 作为兜底：

- `meta.full_text`
- `meta.raw_pages[]`
- `meta.unmapped_segments[]`

## 判断范围

### 普通基础信息字段

以下字段必须 key 存在且值非空：

- `kcbh`：课程编号
- `kkyx`：开课院系
- `zwkcmc`：中文课程名称
- `ywkcmc`：英文课程名称
- `skyy`：授课语言
- `sfyxwxyxk`：是否允许外学院选课
- `khfs`：考核方式
- `kcxz`：课程性质
- `kclb`：课程类别
- `zxs`：周学时
- `skzs`：上课周数
- `zongxs`：总学时
- `jxxs`：教学学时
- `kcxf`：课程学分
- `rkjsxm`：任课教师姓名
- `jsgh`：教师工号
- `email`：E-mail
- `lxdh`：联系电话

### 特殊基础信息字段

以下字段只要求 key 存在，允许值为空：

- `syxs`：实验学时
- `sjxs`：实践学时
- `qtxs`：其他学时
- `zxxs`：自学学时

这四个字段不属于第一维度 `kcjbxxsfykckyz`，只在本维度检查模板 key 是否存在。

### 中英文简介

- `payload.kczwjj`：课程中文简介，必须非空。
- `payload.kcywjj`：课程英文简介，必须非空。

该判断同时计入 `mbxxyzwz`，并单独写入 `zywjj`。

### 其他模板要素

- `payload.ybzsyq`：预备知识要求，必须非空。
- `payload.jcjydcl`：教材及阅读材料，必须非空。
- `payload.kcmb.szmb`：思政目标，必须非空。
- `payload.kcmb.nlmb`：能力目标，必须非空。
- `payload.kcmb.zsmb`：知识目标，必须非空。
- `payload.jxnr.zongxs`：教学内容总学时，必须非空。
- `payload.jxnr.tm[]`：至少一行，且每行 `xh/zt/zsd/xs` 非空。
- `payload.jxap.tm[]`：至少一行，且每行 `zs/sknr/skfs/szyqjxx` 非空。
- 课程要求存在：`payload.kcyq`、`payload.kcyqb.tm[]`、`payload.kcyqb.yqgs` 任一非空即可。

## Meta 兜底策略

payload 是主证据；字段为空或缺 key 时才查 meta。

### 普通字段兜底

meta 中必须在对应语义区域找到“标签 + 非空值”才算存在：

- 基础信息字段：`课程基本信息`、`基本信息`、`课程信息`
- 中英文简介：`课程中文简介`、`课程英文简介`
- 预备知识：`预备知识要求`、`预备知识`
- 教材及阅读材料：`教材及阅读材料`、`教材`、`阅读材料`
- 课程目标：`课程目标`、`教学目标`
- 教学内容：`教学内容`、`课程内容`
- 教学安排：`教学安排`、`课程安排`、`授课安排`、`教学进度`
- 课程要求：`课程要求`

### 特殊字段兜底

当 `syxs/sjxs/qtxs/zxxs` 缺 key 时，只要 meta 在基础信息区域发现对应标签，即使值为空，也视为模板字段存在。

### 表格兜底

表格字段需要在对应章节发现表头或有效行；只有章节标题或孤立关键词不算通过。

### Evidence

兜底成功时写入：

```json
{
  "fallback_used": true,
  "source_path": "meta.raw_pages[0]",
  "section_hint": "课程基本信息",
  "raw_value": "38",
  "snippet": "...",
  "reason": "payload_empty_meta_found"
}
```

特殊字段缺 key 但 meta 发现标签时：

```json
{
  "fallback_used": true,
  "reason": "payload_key_missing_meta_label_found"
}
```

## 输出与入库

### 维度级

写入 `audit_findings`：

```json
{
  "wd": "xxyzwzfhmb",
  "pdfs": "rule",
  "message": "是或否",
  "status": "pass或fail",
  "details": {
    "label": "信息要素完整、符合模板、是否有中英文简介",
    "result": "是或否",
    "reasons": [],
    "checks": {
      "mbxxyzwz": {
        "result": "是或否",
        "reason": "",
        "fail_count": 0
      },
      "zywjj": {
        "result": "是或否",
        "reason": "",
        "fail_count": 0
      }
    }
  },
  "evidence": {
    "failed_paths": [],
    "fallback_paths": [],
    "checks": {}
  },
  "llm_trace": {}
}
```

### 字段级

汇总字段：

```json
{
  "section": "xxyzwzfhmb",
  "field": "mbxxyzwz",
  "path": "audit_findings.xxyzwzfhmb.details.checks.mbxxyzwz",
  "status": "pass或fail"
}
```

缺失字段：

```json
{
  "section": "jcxx",
  "field": "syxs",
  "path": "payload.jcxx.syxs",
  "status": "fail",
  "reason": "实验学时字段缺失",
  "message": "实验学时字段缺失"
}
```

特殊字段 key 存在但值为空：

```json
{
  "section": "jcxx",
  "field": "syxs",
  "path": "payload.jcxx.syxs",
  "status": "pass",
  "message": "实验学时字段存在，允许为空"
}
```

## 不通过原因示例

- `课程中文简介为空`
- `课程英文简介为空`
- `实验学时字段缺失`
- `教学内容表为空`
- `jxnr第 1 行知识点为空`
- `教学安排表为空`
- `jxap第 1 行思政元素的融入和预期教学成效为空`
- `课程要求为空`
- `课程中文简介为空，meta 中仅发现章节标题，未发现有效内容，需人工复核`
