# 维度：课程基本信息是否与课程库一致

## 基本信息

- 维度编码：`kcjbxxsfykckyz`
- 维度名称：课程基本信息是否与课程库一致
- 审核方式：规则审核
- 是否调用 LLM：否
- 结果来源表：`audit_findings`
- 字段明细表：`audit_field_findings`

## 判断目标

判断 PDF 抽取出的课程基本信息是否能唯一定位课程库记录，并与课程库字段精准一致。

该维度不处理 `syxs`、`sjxs`、`qtxs`、`zxxs` 四个字段；这四个字段只在第六维度模板完整性中检查 key 是否存在。

## 输入

### PDF payload

读取 `payload.jcxx`：

- `kcbh`：课程编号
- `kkyx`：开课院系
- `zwkcmc`：中文课程名称
- `ywkcmc`：英文课程名称
- `skyy`：授课语言
- `sfyxwxyxk`：是否允许外学院选课
- `khfs`：考核方式
- `kcxz`：课程性质
- `kclb`：课程类别
- `zxs`：周学时
- `skzs`：上课周数
- `zongxs`：总学时
- `jxxs`：教学学时
- `kcxf`：课程学分
- `rkjsxm`：任课教师姓名
- `jsgh`：教师工号
- `email`：E-mail
- `lxdh`：联系电话

### 课程库

读取匹配到的 `courses` 记录：

- `kcbh`
- `kkyx`
- `zwkcmc`
- `ywkcmc`
- `skyy`
- `yxwxyxk`
- `khfs`
- `kcxz`
- `kclb`
- `zxs`
- `skzs`
- `zongxs`
- `jxxs`
- `kcxf`
- `zjjsxm`

## 课程库定位规则

定位优先级：

1. 优先用 `payload.jcxx.kcbh` 精确匹配 `courses.kcbh`。
2. 若课程编号缺失或查不到，用 `payload.jcxx.zwkcmc` 精确匹配 `courses.zwkcmc`。
3. 若 PDF 内中文课程名缺失，从 `syllabus_extractions.source_path` 文件名提取课程名称，再精确匹配 `courses.zwkcmc`。
4. 只接受唯一命中；无命中或多命中都判为不通过并要求人工复核。

## 字段比对规则

以下字段必须完全一致，且不能双方都为空：

- `payload.jcxx.kcbh` 对 `courses.kcbh`
- `payload.jcxx.kkyx` 对 `courses.kkyx`
- `payload.jcxx.zwkcmc` 对 `courses.zwkcmc`
- `payload.jcxx.ywkcmc` 对 `courses.ywkcmc`
- `payload.jcxx.skyy` 对 `courses.skyy`
- `payload.jcxx.sfyxwxyxk` 对 `courses.yxwxyxk`
- `payload.jcxx.khfs` 对 `courses.khfs`
- `payload.jcxx.kcxz` 对 `courses.kcxz`
- `payload.jcxx.kclb` 对 `courses.kclb`
- `payload.jcxx.zxs` 对 `courses.zxs`
- `payload.jcxx.skzs` 对 `courses.skzs`
- `payload.jcxx.zongxs` 对 `courses.zongxs`
- `payload.jcxx.jxxs` 对 `courses.jxxs`
- `payload.jcxx.kcxf` 对 `courses.kcxf`
- `payload.jcxx.rkjsxm` 对 `courses.zjjsxm`

PDF 自身必填但不与课程库比对：

- `payload.jcxx.jsgh`
- `payload.jcxx.email`
- `payload.jcxx.lxdh`

## 额外规则

- `payload.jcxx.zongxs` 必须等于 `payload.jcxx.zxs × payload.jcxx.skzs`。
- 若 `kcbh` 缺失，不回填 payload；课程定位可使用 `source_path` 兜底。
- 业务字段缺失或不一致不算技术失败，应生成不通过原因。

## 输出与入库

### 维度级

写入 `audit_findings`：

```json
{
  "wd": "kcjbxxsfykckyz",
  "pdfs": "rule",
  "message": "是或否",
  "status": "pass或fail",
  "details": {
    "label": "课程基本信息是否与课程库一致",
    "result": "是或否",
    "reasons": [],
    "course_match": {}
  },
  "evidence": {
    "failed_fields": [],
    "course_match": {}
  },
  "llm_trace": {}
}
```

### 字段级

写入 `audit_field_findings`：

```json
{
  "section": "jcxx",
  "field": "zongxs",
  "path": "payload.jcxx.zongxs",
  "status": "pass或fail",
  "reason": "总学时与课程库不一致：课程库为 38，PDF 为 21",
  "message": "总学时与课程库不一致：课程库为 38，PDF 为 21",
  "expected": "38",
  "actual": "21",
  "evidence": {
    "course_field": "zongxs"
  }
}
```

## 不通过原因示例

- `无法定位课程库记录`
- `文件路径或课程名称匹配到多条课程库记录，需人工复核`
- `课程编号为空`
- `PDF 和课程库中的英文课程名称都为空`
- `总学时与课程库不一致：课程库为 38，PDF 为 21`
- `总学时不等于周学时乘以上课周数：总学时为 38，周学时 3 × 上课周数 7 = 21`
