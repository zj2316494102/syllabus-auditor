# 维度：教学内容是否与学时匹配

## 基本信息

- 维度编码：`jxnrsfyxspp`
- 维度名称：教学内容是否与学时匹配
- 审核方式：规则审核
- 是否调用 LLM：否
- 结果来源表：`audit_findings`
- 字段明细表：`audit_field_findings`

## 判断目标

判断教学内容中的总学时是否与基础信息中的总学时一致。

该维度只比较两个总学时来源，不判断教学内容每一行学时合计是否合理；行学时合计异常作为字段级质量问题另行记录。

## 输入

### 主体输入

- 基础信息总学时：`payload.jcxx.zongxs`
- 教学内容总学时：`payload.jxnr.zongxs`

### meta 辅助输入

仅当结构化字段为空或不可解析时使用：

- `meta.full_text`
- `meta.raw_pages[]`
- `meta.unmapped_segments[]`

## 判断规则

- 两个字段均非空、可解析为数字，且数字相同：通过。
- `payload.jcxx.zongxs` 缺失：不通过，原因写“基础信息总学时为空”。
- `payload.jxnr.zongxs` 缺失：不通过，原因写“教学内容总学时为空”。
- 任一字段不可解析为数字：不通过，原因写“总学时不是可计算数字”。
- 两个数字不一致：不通过，原因写“教学内容总学时与基础信息总学时不一致：基础信息为 X，教学内容为 Y”。

## Meta 兜底策略

meta 兜底必须区分语义来源，不能看到一个孤立“总学时”就同时补给两个字段。

### 基础信息总学时兜底

仅在以下章节附近查找：

- `课程基本信息`
- `基本信息`
- `课程信息`

可识别标签：

- `总学时`
- `课程总学时`

### 教学内容总学时兜底

仅在以下章节附近查找：

- `教学内容`
- `课程内容`

可识别标签：

- `总学时`
- `合计`
- `合计学时`
- `小计`

### 兜底限制

- meta 中孤立、无法归属的“总学时”不作为正式兜底值。
- 若两个字段都缺失，而 meta 中只有一个无法区分来源的总学时，结论为不通过。
- 不回写 payload，只把兜底来源写入 evidence。

## 输出与入库

### 维度级

写入 `audit_findings`：

```json
{
  "wd": "jxnrsfyxspp",
  "pdfs": "rule",
  "message": "是或否",
  "status": "pass或fail",
  "details": {
    "label": "教学内容是否与学时匹配",
    "result": "是或否",
    "reasons": []
  },
  "evidence": {
    "jcxx_zongxs": {},
    "jxnr_zongxs": {},
    "fallback_used": false
  },
  "llm_trace": {}
}
```

### 字段级

写入 `audit_field_findings`：

```json
{
  "section": "jxnr",
  "field": "zongxs",
  "path": "payload.jxnr.zongxs",
  "status": "pass或fail",
  "reason": "教学内容总学时与基础信息总学时不一致：基础信息为 38，教学内容为 21",
  "expected": {
    "path": "payload.jcxx.zongxs",
    "number": 38
  },
  "actual": {
    "path": "payload.jxnr.zongxs",
    "number": 21
  }
}
```

## 不通过原因示例

- `基础信息总学时为空`
- `教学内容总学时为空`
- `基础信息总学时不是可计算数字`
- `教学内容总学时不是可计算数字`
- `meta 中总学时来源无法区分，需人工复核`
- `教学内容总学时与基础信息总学时不一致：基础信息为 38，教学内容为 21`
